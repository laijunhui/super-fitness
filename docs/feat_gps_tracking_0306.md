# GPS轨迹记录功能优化方案

**版本**: 1.0
**日期**: 2026-03-06
**状态**: 方案设计

---

## 1. 现状分析

### 1.1 当前实现

当前`ActiveWorkoutScreen`存在的问题：
- 仅显示数字统计（距离、时长、卡路里）
- 无地图可视化展示
- GPS点已采集但未展示给用户
- 用户无法直观看到运动轨迹

### 1.2 数据模型现状

已有`GPSPoint`模型包含：
- `latitude` / `longitude` - 经纬度
- `timestamp` - 时间戳
- `altitude` - 海拔（可选）
- `speed` - 速度（可选）

运动记录已支持存储`gpsPoints`列表，保存到数据库的JSON字段中。

## 2. 竞品调研

### 2.1 主流健身APP地图功能

| APP | 实时地图 | 轨迹缩略图 | 离线地图 | 地图服务 |
|-----|----------|------------|----------|----------|
| **Keep** | 全屏地图 | 列表卡片小图 | 不支持 | 高德/Google |
| **悦跑圈** | 全屏地图 | 列表卡片小图 | 支持缓存 | 高德 |
| **Strava** | 全屏地图 | 详情页大图 | 支持 | Google |
| **Nike Run** | 半屏地图 | 路线概览图 | 部分支持 | Apple Maps |

### 2.2 关键交互模式

1. **实时运动中**：
   - 半屏地图 + 半屏数据（主流方案）
   - 全屏数据 + 小地图浮窗
   - 全屏地图 + 底部数据栏

2. **运动记录列表**：
   - 缩略图卡片（左图右文）
   - 纯文字 + 路线距离

3. **运动详情**：
   - 全屏可交互地图
   - 路线统计摘要

#### 技术方案（国产地图SDK）

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 地图SDK | `amap_flutter_map` (高德) | 国内生态成熟 |
| 定位SDK | `amap_flutter_location` | 高德定位更精准 |
| 轨迹渲染 | Polyline + 渐变色 | 高德SDK自带 |
| 缩略图 | 地图快照API | 高德提供截图能力 |

**备选方案**：如高德SDK不支持Flutter，可考虑：
- `flutter_baidumap` (百度地图)
- `tencent_map_sdk` (腾讯地图)

#### 技术实现要点

1. **高德地图集成**：
   - 申请高德地图API Key（需要在高德开放平台注册）
   - 配置`AndroidManifest.xml`和`Info.plist`
   - 使用`AMapView`展示地图

2. **实时地图**：
   - 使用`AMapView`替换纯数据展示
   - `PolylineOptions`绘制轨迹线
   - `MyLocationStyle`显示当前位置
   - 监听定位更新实时刷新

3. **缩略图生成**：
   - 使用高德地图快照功能
   - 保存为Base64或文件到本地
   - 列表页直接加载缩略图

4. **数据存储**：
   ```dart
   // 新增字段
   exercise.thumbnail // 缩略图Base64
   exercise.boundingBox // 轨迹边界用于缩略图裁剪
   ```

#### 优点

- 实时反馈强，用户可见运动轨迹
- 交互自然，主流用户习惯
- 高德地图国内访问稳定
- GPS定位精准（支持北斗）
- 高德SDK功能完善

#### 缺点

- 需要申请高德API Key
- 需要配置平台密钥
- 缩略图生成有性能开销

```
│   │       时长          │   │

└─────────────────────────────┘
```

#### 技术方案

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 实时追踪 | 保持现有geolocator | 仅记录数据 |
| 详情地图 | `url_launcher`打开高德/百度地图 | 无需集成SDK |
| 轨迹分享 | 生成KML/GPX文件 | 通用格式 |
| 缩略图 | 不生成 | 节省存储 |

#### 技术实现要点

1. **数据记录优化**：
   - 优化GPS采样频率（每3-5秒）
   - 添加轨迹平滑处理
   - 记录起点终点坐标

2. **系统地图唤起**：
   ```dart
   // 高德地图URL Scheme
   final url = 'https://www.amap.com/search?query=${endLat},${endLng}';
   // 或使用URI Scheme
   final uri = 'iosamap://navi?sourceApplication=super_fitness&poi=${endLat},${endLng}';
   await launchUrl(Uri.parse(uri));
   ```

3. **轨迹导出**：
   - 生成GPX格式文件
   - 支持分享到其他应用

#### 优点

- 无需地图SDK集成，开发量最小
- 系统地图体验原生
- 无存储缩略图开销
- 无需API Key费用

#### 缺点

- 实时运动时无地图反馈
- 用户无法在运动中看到轨迹
- 依赖系统地图应用（可能未安装）
- 无法显示实时配速

## 4. 方案对比

| 对比项 | 方案A（高德实时地图） | 方案B（纯数据+系统地图） |
|--------|----------------------|--------------------------|
| **用户实时体验** | ★★★★★ 实时可见轨迹 | ★☆☆☆☆ 仅数字展示 |

## 5. 实施计划

### 阶段一：地图SDK集成（1-2天）

1. **申请高德地图API Key**
   - 注册[高德开放平台](https://console.amap.com)账号
   - 创建应用，获取Key（需要绑定包名）
   - 配置Android和iOS平台

2. **集成SDK**
   ```yaml
   # pubspec.yaml
   dependencies:
     amap_flutter_map: ^3.0.0
     amap_flutter_location: ^4.0.0
   ```

3. **配置平台**
   - Android: 在`AndroidManifest.xml`中添加Key
   - iOS: 在`Info.plist`中添加NSLocationUsageDescription

### 阶段二：实时轨迹功能（1-2天）

1. **实时地图页面**
   - 替换现有数据面板为半屏地图
   - 绘制实时轨迹线
   - 当前位置标记
   - 保留底部数据面板

2. **轨迹记录优化**
   - GPS采样频率调优
   - 轨迹平滑处理
   - 起点/终点记录

### 阶段三：详情页与缩略图（1天）

1. **详情页全屏地图**
   - 全屏展示完整轨迹
   - 起点/终点标记
   - 可交互（缩放、拖动）

2. **缩略图功能**
   - 地图快照生成
   - 存储到本地
   - 列表页展示
