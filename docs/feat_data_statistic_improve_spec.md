# 数据统计页面改进需求规格说明

## 1. 需求概述

优化数据统计页面的柱状图交互体验，使图表更直观易懂，并提供日期筛选的快捷入口。

## 2. 需求背景

当前数据统计页面的柱状图存在以下问题：
- 缺少坐标轴标签，无法直观理解X轴（日期）和Y轴（时长）的含义
- 柱形仅显示高度，缺少具体数值标注
- 用户无法快速查看某一天的具体运动记录，需要手动切换到运动列表页面查找

## 3. 功能需求

### 3.1 柱状图增强

#### 3.1.1 X轴优化
- 显示日期标签，格式根据筛选周期动态调整
  - 7天筛选：显示"周一"、"周二"等星期几
  - 30天筛选：显示"1"、"8"、"15"、"22"、"29"等日期数字
- 文字大小：10px
- 文字颜色：跟随主题（浅色/深色模式）

#### 3.1.2 Y轴优化
- 显示时长刻度，单位为"分钟"
- 刻度值根据数据最大值动态计算
- 建议显示 0、1/4、1/2、3/4、MAX 五个刻度点
- 文字大小：10px
- 文字颜色：跟随主题

#### 3.1.3 柱形增强
- 柱形上方显示具体数值，格式：`次数|时长分钟`
- 例如："2|45" 表示2次运动，共45分钟
- 数值文字大小：10px
- 数值文字颜色：跟随主题

### 3.2 柱形点击交互

#### 3.2.1 点击行为
- 点击某个柱形后，高亮选中状态
- 在图表下方展开当日运动记录列表

#### 3.2.2 记录列表展示
- 标题显示选中日期，格式："YYYY年MM月DD日 的运动记录"
- 列表样式与运动列表页面（`ExerciseListScreen`）保持一致
- 使用 `ExerciseMapCard` 组件展示每条记录
- 如果当天没有运动记录，显示"当日无运动记录"的空状态提示

#### 3.2.3 取消选择
- 再次点击已选中的柱形，取消选中状态
- 点击其他柱形，切换选中日期

## 4. 技术实现方案

### 4.1 状态管理

在 `StatisticsProvider` 中添加：
- `_selectedDate`: 当前选中的日期（可选）
- `selectedDate`: Getter方法
- `selectedDateExercises`: 选中日期的运动记录列表
- `selectDate(DateTime date)`: 选中日期
- `clearSelection()`: 清除选中状态

### 4.2 UI组件

#### 4.2.1 自定义柱状图组件
- 使用 `CustomPaint` 或 `fl_chart` 库绘制
- 接收 `List<DailyStatsData>` 数据
- 提供 `onBarTap(DateTime date)` 回调

#### 4.2.2 选中日期记录列表
- 在图表下方条件渲染
- 使用 `AnimatedContainer` 实现展开/收起动画
- 动画时长：300ms

### 4.3 数据获取

```dart
// 在 StatisticsProvider 中添加方法
Future<void> loadExercisesByDate(DateTime date) async {
  final exercises = await _exerciseRepository.getExercisesByDateRange(
    date,
    date,
  );
  _selectedDateExercises = exercises;
  notifyListeners();
}
```

## 6. 验收标准

### 6.1 功能验收
- [ ] 柱状图X轴显示正确的日期标签（星期/日期）
- [ ] 柱状图Y轴显示时长刻度和"分钟"单位
- [ ] 每个柱形上方显示"次数|时长"数值
- [ ] 点击柱形后，页面下方展开当日运动记录列表
- [ ] 记录列表显示与运动列表页面一致的卡片样式
- [ ] 再次点击选中柱形，可收起记录列表
- [ ] 切换周期（如7天到30天），自动清除选中状态

### 6.2 视觉验收
- [ ] 浅色模式下图表元素颜色正确
- [ ] 深色模式下图表元素颜色正确
- [ ] 柱形高度与时长数据成正比
- [ ] 数值标签不超出图表边界

### 6.3 交互验收
- [ ] 点击响应灵敏，无明显延迟
- [ ] 列表展开/收起动画流畅
- [ ] 空数据状态显示正确提示
