# 常练习的运动功能规格说明

## 1. 需求概述

在运动页面增加「常练习的运动」模块，展示推荐的教程视频，供用户快速开始训练。

## 2. 功能需求

### 2.1 位置
- 位于「快速开始」下方，「最近记录」上方

### 2.2 内容
- 展示 TOP 3 推荐视频
- 每个视频卡片包含：
  - 视频封面缩略图
  - 视频标题
  - 难度标签
  - 视频时长
  - 播放按钮

### 2.3 交互
- 点击视频卡片 → 跳转到视频播放页
- 点击播放按钮 → 跳转到视频播放页
- 点击「查看全部」→ 跳转到教程列表页

## 4. 技术方案

### 4.1 数据来源
- 使用现有的 `TutorialProvider` 获取视频数据
- 取前 3 条视频作为推荐

### 4.2 组件复用
- 视频缩略图：使用 `TutorialVideo.thumbnailUrlResolved`（自动根据视频来源选择B站封面或YouTube缩略图）
- 视频时长：使用 `TutorialVideo.durationFormatted`
- 难度标签：使用 `TutorialVideo.difficultyText`

### 4.3 路由
- `/tutorials` - 教程列表页
- `/tutorials/:id` - 视频播放页

## 5. 配套修改

### 5.1 运动类型名称调整
将「健身」改为「室内运动」以更准确描述运动类型。

修改文件：`lib/core/constants/app_constants.dart`

```dart
case ExerciseType.gym:
  return '室内运动';
```
